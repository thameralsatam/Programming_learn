# Studio Lab

A browser-based code editor for learning web development: write HTML, CSS, and JavaScript, see the result live, and manage multiple projects — designed to be simple and mobile-friendly, without ads or accounts.

**Live:** https://code-learn.pages.dev

## Features

- Multiple projects with automatic local saving
- File and folder tree
- Monaco editor with Emmet support
- Live preview inside a phone-shaped frame
- Console output with error boundaries
- Workspace export/import as ZIP

## Tech Stack

- React 19 + TypeScript + Vite + Tailwind CSS
- Monaco Editor
- localStorage persistence (fully client-side)

## Status

Work in progress: the AI assistant feature is disabled and the error console is not complete yet.

## Development

```bash
npm install
npm run dev
```
